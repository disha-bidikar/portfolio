# Portfolio

## About

This is a **modern portfolio website** built to showcase my skills, projects, and experience. It is a simple, responsive static site made with vanilla HTML, CSS & JavaScript.  
It aims to provide a clean and professional online presence.

---

## Features

- Responsive design for both desktop & mobile  
- Smooth scrolling navigation  
- Projects / Skills sections  
- Contact information / link outs  
- Lightweight & fast — no heavy frameworks  
- Easy to customise
